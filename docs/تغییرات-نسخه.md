# تغییرات نسخه — v1.3

> تاریخ: ۲۰ نوامبر ۲۰۲۶

## این نسخه چه اضافه کرد

### ۱. لینک کل دانش (زنده)
- `/report/all` + `/api/report/all`
- با هر منبع یا دستهٔ جدید خودکار به‌روز می‌شود
- نمایش در پنل بخش «لینک‌های پایدار»

### ۲. فهرست منابع (برای IronPin)
- `/report/sources` + `/api/sources`
- خروجی `ironpin-sources-v1` با kind/readable/state

### ۳. مصرف روزانه Cloudflare
- `/api/usage` + نمایش در پنل
- حجم D1 از ۵۰۰MB سقف فری + درصد
- ردیف خوانده/نوشته‌شده و درخواست Worker (GraphQL)

### ۴. حذف قیمت → فقط دستی
- حذف خودکار در cron **غیرفعال** شد
- `POST /api/prices/delete { older_than_days }`
- دکمه در پنل با تأیید
- **فقط** ردیف‌های `attribute/layer/tags = price`
- دانش فنی و توضیحی (حتی با کلمهٔ «قیمت» در متن) هرگز پاک نمی‌شود
- چرخهٔ X روز هم فقط از همین مسیر دستی

### ۵. منبع مرده vs زنده
- صفحهٔ ناموفق مکرر → `source.state=dead` (دیگر enqueue نمی‌شود)
- صفحهٔ موفق با دانش → `source.state=live`
- اثبات: ۳۰۷۵+ ایتم از منابع finder

### ۶. صف بروزرسانی
- دکمهٔ بروزرسانی همان لحظه `drainQueue` اجرا می‌کند
- اولویت منصفانه بین صف و fetch
