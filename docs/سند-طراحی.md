## ۱. هدف

ربات خودکار استخراج قیمت فولاد از وب — **آینه اسکنر داخلی آیرون پین**:

1. موضوع قیمت را جستجو و صفحات را می‌خواند
2. متن را با جستجوگر ۱ (TextPriceEngine) استخراج می‌کند و مستقیماً به **ردیف Quote** تبدیل می‌کند (محصول + مشخصات + قیمت + ماده؛ بدون جمله اضافی)
3. لینک گزارش می‌دهد (تکی / لیستی / همه)
4. با Cron بدون حضور کاربر کار می‌کند
5. منابع را مثل IronPin کشف و تازه‌سازی می‌کند

مسیر RAG/چانک کوئن و بخش دانش کوئن **حذف** شده است (v1.6).

## ۴. چرخهٔ داده

### ۴.۱ اسکن
```
topic → searchWeb (۳ کوئری) → pages(pending)
      → fetch (۵ صفحه/tick، موازی) → extract (متن+جدول+تصویر) → ironpin_quotes
```

### ۴.۲ کشف منبع (جستجوگر ۲)
```
هر round: بانک‌های query چرخشی (FINDER_PART_TITLES)
  → classifyLink → sources (state=new)
  → enqueue readable → harvest scan → fetch → ironpin_quotes
  → صفحه موفق → source.state=live
  → شکست مکرر → source.state=dead (دیگر enqueue نمی‌شود)
```

**اثبات:** ۳۰۷۵+ ایتم دانش از صفحات `source=finder` استخراج شده — منبع مرده وارد چرخه نمی‌شود.

### ۴.۳ حذف قیمت — فقط دستی
```
خودکار: غیرفعال (runPriceRetention → disabled_auto)
دستی:   POST /api/prices/delete { older_than_days: X }
        DELETE فقط ردیف‌هایی که:
          attribute='price' OR layer='price' OR tags LIKE '%"price"%'
        هرگز: claim متنی، specs، basics، دانش فنی
```

## ۵. فرمت خروجی (ironpin-quotes-v1)

```json
{
  "format": "ironpin-quotes-v1",
  "generated_at": "…", "count": 1234, "cursor": 1234567890, "complete": true,
  "quotes": [{ "id", "title", "amount", "currency": "تومان", "sourceDateRaw": "…", "sellerCity": "اصفهان", … }]
}
```

قوانین: مبالغ فقط **تومان** (ریال÷۱۰ با ثبت مبنا)؛ ردیف بی‌قیمت صادر نمی‌شود؛
dedup هویت+روز ایرانی؛ اسنپ‌شات کامل = ۳۰ روز اخیر (سقف ۱۲۰۰۰)؛
`?since=` incremental با `cursor`.

## ۶. Cron

| زمان | کار |
|------|-----|
| `* * * * *` | processIronpinBatch (materialize) |
| `*/5 * * * *` | ensureSchema → seed → purge → finder → drainQueue(30) |
| `0 */6 * * *` | + requeueDueScans (بازتازه‌سازی خودکار) |

**حذف قیمت در cron اجرا نمی‌شود.**

## ۷. مصرف Cloudflare

- `/api/usage` → حجم D1 (MB) / سقف **۵۰۰MB** / درصد
- ردیف خوانده/نوشته‌شدهٔ روز (GraphQL) + درخواست Worker
- Secret: `CF_API_TOKEN`, `CF_ACCOUNT_ID`, `CF_D1_ID`
- نمایش در پنل بخش «مصرف روزانه»

## ۸. استقرار

```bash
npm install
npx wrangler d1 execute qwen_scanner --file=./schema.sql --remote
npx wrangler secret put CF_API_TOKEN
npx wrangler deploy
```

تست‌ها: `npm test` — smoke · finder ۱۶ · ironpin · guardian · pipeline · table_reader · city (۷ سوئیت، همه سبز).
