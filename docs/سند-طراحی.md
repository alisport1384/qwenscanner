# سند طراحی — اسکنر قیمت فولاد Qwen

> نسخه: **۱.۳**
> تاریخ: **۲۰ نوامبر ۲۰۲۶**
> پلتفرم: Cloudflare Workers + D1 (رایگان)
> آدرس عملی: `https://qwen.alisport0.qzz.io/`
> مخزن: `https://github.com/alisport1384/qwenscanner`

---

## ۱. هدف

ربات خودکار استخراج دانش قیمت فولاد از وب:

1. موضوع قیمت را جستجو و صفحات را می‌خواند
2. متن را چانک و به **KnowledgeItem** تبدیل می‌کند (فرمت Qwen)
3. لینک گزارش می‌دهد (تکی / لیستی / **کل دانش**)
4. با Cron بدون حضور کاربر کار می‌کند
5. منابع را مثل IronPin کشف و تازه‌سازی می‌کند

## ۴. چرخهٔ داده

### ۴.۱ اسکن
```
topic → searchWeb (۳ کوئری) → pages(pending)
      → fetch (۵ صفحه/tick) → extract → chunk → knowledge
```

### ۴.۲ کشف منبع (جستجوگر ۲)
```
هر ۲۰ دقیقه: ۳ لیست × ۵ کوئری
  → classifyLink → sources (state=new)
  → enqueue readable → harvest scan → fetch → knowledge
  → صفحه موفق → source.state=live
  → شکست مکرر → source.state=dead (دیگر enqueue نمی‌شود)
```

**اثبات:** ۳۰۷۵+ ایتم دانش از صفحات `source=finder` استخراج شده — منبع مرده وارد چرخه نمی‌شود.

### ۴.۳ حذف قیمت — فقط دستی
```
خودکار: غیرفعال (runPriceRetention → disabled_auto)
دستی:   POST /api/prices/delete { older_than_days: X }
        DELETE فقط ردیف‌هایی که:
          attribute='price' OR layer='price' OR tags LIKE '%"price"%'
        هرگز: claim متنی، specs، basics، دانش فنی
```

  "format": "qwen-knowledge-v1",
  "kind": "all | batch | scan",
  "chunker": { "target_chars": 900, "overlap_chars": 140, "min_chars": 200 },

  "items": [{ "id", "topic", "claim", "url", "domain", "confidence", "kind", "tags" }]
}
```

## ۶. Cron

| زمان | کار |
|------|-----|
| `*/5 * * * *` | ensureSchema → seed → finder → drainQueue(30) |
| `0 */6 * * *` | + requeueDueScans (بازتازه‌سازی خودکار) |

**حذف قیمت در cron اجرا نمی‌شود.**

---

## ۷. مصرف Cloudflare

- `/api/usage` → حجم D1 (MB) / سقف **۵۰۰MB** / درصد
- ردیف خوانده/نوشته‌شدهٔ روز (GraphQL) + درخواست Worker
- Secret: `CF_API_TOKEN`, `CF_ACCOUNT_ID`, `CF_D1_ID`
- نمایش در پنل بخش «مصرف روزانه»

## ۸. استقرار

npx wrangler secret put CF_API_TOKEN
npx wrangler deploy
```

## ۹. ملاحظات D1 رایگان

| سقف | مقدار |
|-----|-------|
