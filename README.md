# qwenscanner — سرور هوش جستجوگر ۲ برای آیرون‌پین

این پروژه بر پایهٔ **Cloudflare Workers + D1** به‌صورت اختصاصی برای اجرای آنلاین **هوش جستجوگر ۲ (Searcher-2)** طراحی شده است و هیچ‌گونه استخراج ردیف قیمت یا OCR روی سرور انجام نمی‌دهد.

## کارکرد سرور
1. **جستجو در ۹ موتور جستجو و ۶ دایرکتوری کانال ایرانی**:
   - موتورهای جستجو: `ddg-lite`, `yahoo`, `bing`, `ddg`, `naver`, `bing-html`, `yahoo-ca`, `gerdoo`, `zarebin`
   - دایرکتوری‌های کانال: `mychannels.ir`, `canaljoo.ir`, `canalha.ir`, `joinchannel.ir`, `cafechannel.ir`, `linkdoniwebsit.ir`
2. **کشف و تفکیک ۳ فهرست منبع**:
   - وب‌سایت‌های فروش و پخش کالا (`part=0`)
   - شبکه‌های اجتماعی (`part=1`: تلگرام، اینستاگرام، واتساپ)
   - شبکه‌های داخلی (`part=2`: ایتا، بله، روبیکا، سروش، آی‌گپ، گپ)
3. **راستی‌آزمایی و پیمایش عمیق تا عمق ۲**:
   - بررسی صفحهٔ عمومی، شواهد فروش مقاطع فولادی (`sellsGoods`)، جدول قیمت، `og:site_name`، اطلاعات تماس، لینک‌های داخلی قیمت و لینک کانال‌های معرفی‌شده.
4. **چرخه خودکار ۲۴ ساعته (قابل تنظیم)** + **ورودی محصولات سفارشی**:
   - افزودن محصول دلخواه در پنل وب باعث صف‌شدن پرس‌وجوهای اختصاصی و ذخیرهٔ منابع جدید آن محصول می‌شود.
5. **خروجی استاندارد برای IronPin**:
   - `GET /api/sources` (فرمت `ironpin-sources-v1`) — توسط نسخهٔ `0.9.15+` آیرون‌پین در حالت خارجی دریافت و با جستجوگر ۱ + OCR داخلی گوشی خوانده می‌شود.
   - `GET /api/status` — وضعیت سبک پنل، موتورها، محصولات و نگهبان‌های پلن رایگان Cloudflare (بدون بارگذاری لیست منابع).
   - صفحه اختصاصی `/sources` — نمایش و جستجوی لیست کامل منابع برای سبک ماندن لودینگ صفحه اصلی.
   - `POST /api/sources/purge` — پاک‌سازی دستی منابع قدیمی‌تر از بازهٔ نگهداری (پیش‌فرض ۶ ماه، قابل تغییر) یا پاک کردن دستی تمام منابع.
