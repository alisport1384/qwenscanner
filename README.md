# اسکنر آنلاین آیرون پین (IronPin Scanner)

آینه اسکنر داخلی آیرون پین — اسکنر خودکار قیمت فولاد و مقاطع فلزی روی
Cloudflare Workers + D1. بدون حضور کاربر کار می‌کند: جستجو، دریافت،
استخراج، ذخیره و گزارش کاملاً خودکار.

**پنل:** https://qwen.alisport0.qzz.io/

## قابلیت‌ها

- **جستجوگر ۱**: محصولات فولادی (میلگرد، تیرآهن، هاش، نبشی، ناودانی،
  پروفیل/قوطی، لوله، ورق، پلیت، بولت، توری، شمشت، ...) با قیمت به **تومان**،
 تاریخ/زمان به‌روز، واحد متداول، مالیات، واحد فروش، تبدیل واحد و
 آدرس/آدرس‌از-تلفن، و استخراج از تصویر.
- **جستجوگر ۲**: کشف منابع/محصولات جدید و ارائه نتایج به جستجوگر ۱.
- ردیفهای ثبت‌شده فقط **محصول + مشخصات + قیمت + ماده** — بدون جمله
  اضافی.
- تشخیص ارز **تومان** و تبدیل **ریال → تومان** (ریال ÷ ۱۰).
- اسکنر دقیقاً آینه اسکنر داخلی آیرون پین است.
- نگهبان اسکنر با حداقل مصرف CPU/D1/حجم/درخواست روزانه.
- حذف لینک‌های زباله از خروجی.

## لینک‌ها

| لینک | توضیح |
|------|-------|
| [/report/all](https://qwen.alisport0.qzz.io/report/all) | گزارش‌های اسکنر (زنده) |
| [/api/report/all](https://qwen.alisport0.qzz.io/api/report/all) | JSON گزارش‌ها |
| [/api/ironpin](https://qwen.alisport0.qzz.io/api/ironpin) | ردیف‌های Quote (IronPin)؛ اسنپ‌شات کامل = پنجرهٔ ۳۰ روز اخیر (dedup هویت+روز، سقف ۱۲۰۰۰)؛ `?since=<ms>` = حالت incremental با `cursor` |
| [/report/sources](https://qwen.alisport0.qzz.io/report/sources) | فهرست منابع (IronPin) |
| [/api/sources](https://qwen.alisport0.qzz.io/api/sources) | JSON منابع |
| [/api/usage](https://qwen.alisport0.qzz.io/api/usage) | مصرف روزانه CF/D1 |

> مسیر RAG/چانکی مدل کوئن و بخش دانش کوئن حذف شده است (**حذف**) —
> خروجی تنها ردیف‌های قیمت آیرون‌پین است.

## قواعد کلیدی

- **نگهبان اسکنر**: سقف دیواری هر cron (۱۸ ثانیه)، درخواست خروجی روزانه
  (۷۰۰)، خواندن D1 (۴٫۵M)، فراخوانی تصویر روزانه (۶۰) — حداقل مصرف پیش‌فرض
- **استخراج از تصویر**: مدل Clairic، فقط ردیفِ دارای قیمت/محصول، بدون جمله
  اضافی
- **حذف قیمت فقط دستی**
- منبع مرده (`state=dead`) دوباره اسکن نمی‌شود
- `/report/all` با هر افزوده جدید خودکار به‌روز است
- شهر فروشنده از شاهد مکتوب صفحه (تلفن ثابت > آدرس/تحویل > نقشه) تشخیص داده می‌شود؛ نام کارخانه شهر نمی‌سازد
- تاریخ منبع در لحظه سرویس مرمت می‌شود؛ ردیف دارای تاریخ نامعتبر هرگز خارج نمی‌شود
